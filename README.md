 # Anurag Jaiswal Portfolio

 A modern, responsive personal portfolio built with React and Vite. The site introduces Anurag, highlights his skills and projects, and provides a way to get in touch.

 ## Features

 - Responsive portfolio layout
 - Hero section with personal introduction
 - About section
 - Skills showcase
 - Projects section
 - Contact section
 - Reusable React components

 ## Tech Stack

 - React
 - Vite
 - JavaScript (JSX)
 - CSS3

 ## Getting Started

 ### Prerequisites

 Make sure you have [Node.js](https://nodejs.org/) installed.

 ### Installation

 1. Clone the repository:

	 ```bash
	 git clone <repository-url>
	 cd "Anurag Jaiswal Portfolio"
	 ```

 2. Install dependencies:

	 ```bash
	 npm install
	 ```

 3. Start the development server:

	 ```bash
	 npm run dev
	 ```

 4. Open the local URL shown in the terminal.

 ## Available Scripts

 - `npm run dev` — Start the development server.
 - `npm run build` — Create a production build.
 - `npm run preview` — Preview the production build locally.

 ## Customization

 Update the content in `src/Components/` and adjust the styling in `src/App.css` or `src/index.css` to personalize the portfolio.
